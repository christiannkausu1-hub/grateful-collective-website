SUPPLIER / TRADE PAYABLES UPDATE
- Supplier add card and all panels/cards in Trade Payables now use the site's collapsible-card mechanism and start closed when the page opens.
- Removed supplier email, address/notes, and supplier status fields from Add Supplier.
- Removed invoice number, URL, and notes entry fields. Invoice references are generated automatically when an invoice is saved.
- Added repayment terms: daily instalment or lump sum, amount, payment date, and a live repayment-plan preview.
- Supplier register now always renders its column headings, sorts suppliers client-side, compares supplier IDs consistently, and shows a specific database refresh error instead of appearing silently empty.
- Added repayment_type, repayment_amount, and repayment_date columns to GC_PAYABLES_UPGRADE.sql. This database migration is required before saving invoices with the new repayment terms.
- No existing supplier or payable records are deleted by the code changes.
